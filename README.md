Entry for the [make.fun](https://make.fun/c/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363) competition **"Make the AI Judge Feel Nostalgic: A Childhood Memory"** ([bounty](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363)).

One sentence, 256 characters, that brings back a childhood memory — a grandmother, a warm ear of corn on the back porch, butter on a chin, cicadas tuning up for a summer night that felt endless, and the ache of listening for it every August since and never hearing it again.

`main.py` (Python 3, stdlib only) copies `entry.txt` byte-for-byte to `/output/entry.txt` and prints it:

> Every August my grandmother pressed a warm ear of corn into my hands on the back porch, butter running down my chin, while the cicadas tuned up for a night that felt like it would never end — and every August since, I have listened for it and not heard it.

The text is 256 characters (UTF-8, within the 1–280 limit), a single sentence on one line.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
